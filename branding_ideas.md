# SproutPenny Branding Ideas

## Name styling
- **Product name (UI):** SproutPenny
- **Marketing name (copy):** Sprout Penny
- **Domain:** sproutpenny.com

## Tagline ideas (pick a direction)
1) Calm + practical: **“Budgeting that feels doable.”**
2) Checkbook vibe: **“A simple checkbook you’ll actually use.”**
3) Future-proof: **“See what’s coming. Stay ahead.”**
4) Bills/reminders: **“Never get surprised by due dates.”**
5) Friendly: **“Grow your money habits.”**

## Visual direction (simple, non-fintech-bro)
### Icon concepts
- A **sprout growing out of a penny**
- A **penny jar with a sprout**
- A **leaf + coin** in a clean circle badge

### Palette (easy win)
- **Primary:** deep leaf green
- **Accent:** warm copper
- **Background:** off-white / very light sand

### Fonts
- **UI:** Inter (clean)
- **Logo/wordmark:** Nunito or Poppins (friendly)

## Cloudflare setup checklist (fast)
- Add DNS records for `sproutpenny.com` (and optionally `www`)
- Enable **Full (strict)** SSL
- Create a redirect rule: `www.sproutpenny.com` → `sproutpenny.com` (or vice versa)
- Optional: add `app.sproutpenny.com` for the Blazor app, keep root domain for a landing page/docs
