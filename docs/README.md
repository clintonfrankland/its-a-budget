# Budget App User Guide

Welcome! This guide walks you through each page of the Budget App from a user point of view.

This app is designed to be simple, fast, and practical. It helps you:

- Keep a clean checkbook style ledger (with running balance)
- Track which transactions have cleared
- Plan ahead with upcoming bills and budget items
- Forecast your balance over time so surprises are harder to sneak up on you
- Keep your accounts organized in one place

## A quick note about buttons and icons

You’ll see a few common actions throughout the app:

- **Add** (usually a plus icon): create something new
- **Edit** (pencil icon): change an existing item
- **Delete** (trash icon): remove an item
- **Search**: type to quickly filter a list

If you’re on a small screen (like a phone), some actions tuck into a single menu button to save space. Same features, just a more compact layout.
