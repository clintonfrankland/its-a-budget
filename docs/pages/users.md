# Users (Admin)

## What this page is

The **Users** page is for **administrators**.

It’s where you manage who can access the It's a Budget and what permissions they have.

If you are not an admin, you won’t be able to access this page.

## What you’ll see

A list of users in the system. For each user you may see details like:

- username
- display name
- email address
- whether the user is an administrator

The list is designed to be searchable and easy to scan.

## Common tasks

### Add a new user

Use the **Add** action to create a new user.

You’ll typically set:

- username
- display name
- email address
- admin access (if appropriate)

### Edit a user

Use **Edit** next to a user to update their information.

This is how you fix things like:

- name changes
- email updates
- switching admin rights on or off

### Password and access help

Admins can help users regain access by updating credentials or using the password-related tools available on the page.

## Why this page is useful

A budgeting system is personal, so access control matters.

The Users page gives you a clean way to keep the app secure without making administration feel like a full-time job.
