# Insights

The Insights page summarizes expense transactions for the signed-in user.

Open it from the main navigation with **Insights**. Guests are redirected to sign in before any report data is shown.

## Month selector

Insights defaults to the current month. Use the month selector at the top of the page to view a different month.

Dates and currency follow the app-wide `en-US` formatting policy.

## Reports

**Spending by Category** shows expense transactions only, grouped by category for the selected month and sorted by highest spending first. Transactions whose category is missing, blank, or outside the current user scope are grouped as **Uncategorized**.

**Category Trend** shows the same expense-category grouping across seven month columns: the selected month plus the previous six months. Months without spending show `$0.00`.

**Top Payees** shows the highest expense payees for the selected month, sorted by total spending. Deleted payees are still included when historical transactions point to them so old transaction names remain visible. Missing or out-of-scope payees are grouped as **Unknown payee**.

## Limitations

Insights reports expenses only by default. Income, transfers, account-level filtering, custom date ranges, and charts are not included in this first simple reporting view.
